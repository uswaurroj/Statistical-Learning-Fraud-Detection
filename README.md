# Statistical Learning for Anomaly & Fraud Detection

An empirical statistical learning framework for evaluating high-dimensional transaction data to detect anomalous patterns and financial fraud.

## Methodology
- **Statistical Modeling:** Isolation Forest & Z-Score anomaly thresholding.
- **Data Preprocessing:** Standard scaling & synthetic transaction generation.
- **Evaluation:** Precision, Recall, and F1-Score benchmarking on imbalanced datasets.
